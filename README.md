# Screening de riesgo de adicción al celular

App del TP2 de Análisis Predictivo Avanzado. Se completa la encuesta de un alumno y una red neuronal (perceptrón multicapa) estima la probabilidad de riesgo Bajo, Moderado o Alto, y si conviene convocarlo al gabinete.

Correr local: `pip install -r requirements.txt` y `streamlit run app.py`
